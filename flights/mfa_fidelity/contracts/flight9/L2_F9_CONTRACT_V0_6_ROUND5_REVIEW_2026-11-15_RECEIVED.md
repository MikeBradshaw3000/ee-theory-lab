## 4. R5-1 — The near-θ split is made on the wrong quantity

### 4.1 The quantity at issue

For a constant pre-noise map, write

**a(c) = E[clip(c + σ_seed(c) Z, 0, 1)].**

This is the scalar value of its population map. Because that map is spatially constant, the 3×3 mean leaves a(c) unchanged. The contract's population region is therefore empty when a(c) < θ and full when a(c) ≥ θ. The relevant population distance is **|a(c) − θ|**, not |c − θ|. [C §§5.5 steps 1–4, 6.0–6.2.]

V0.6 instead assigns the capped constant quota using c ∈ [0.03, 0.14] ∪ [0.26, 0.40], and row 25 using c ∈ (0.14, 0.26). Its typed certificate checks empty/full status, but imposes no distance condition on a(c). Clipping can move a low c upward substantially. Constancy is preserved; distance from θ is not.

The distinction matters to the accepted ruling. R4 §6.3 explains the original issue in terms of a constant **population** map close to θ. I §2.1 grounds Mike's choice in whether a required arm has a flat **population** map. C's header, A7 and §11.1(iv) then describe near-θ flat-map behavior as uncapped, while §§6.0–6.2 identify the clipped map as the truth target. A completely specified pre-noise draw law does not by itself implement that population-domain policy. [R4 §6.3; I §2.1; C header, §§1.5 A7, 6.0–6.2, 11.1(iv).]

## Appendix R — Reproducible analytical witnesses

This program uses only the declared scalar clipping formula and synthetic arrays. The optional root calculation demonstrates an interior intercept whose population mean reaches θ. The fixed 40-seed construction demonstrates compatibility of a nearby bin SD with the relevant calibration summaries; it is not a full calibration census.

~~~python
import math
import numpy as np
from scipy.special import ndtr
from scipy.optimize import brentq

theta = 0.20

def clipped_mean(c, sigma):
    if sigma == 0:
        return float(c)
    a = -c / sigma
    b = (1.0 - c) / sigma
    phi = lambda z: math.exp(-0.5*z*z) / math.sqrt(2.0*math.pi)
    return float(
        c * (ndtr(b) - ndtr(a))
        - sigma * (phi(b) - phi(a))
        + 1.0 - ndtr(b)
    )

# Interior example: row 15 accepts a population map close to theta.
near = clipped_mean(0.13, 0.31)
assert 0.03 < 0.13 < 0.14
assert abs(near - theta) < 0.001
print("c=.13, sigma=.31:", near)

# Reverse example: row 25 accepts a population map outside the band.
far = clipped_mean(0.25, 0.35)
assert 0.14 < 0.25 < 0.26
assert abs(far - theta) > 0.06
print("c=.25, sigma=.35:", far)

s = brentq(
    lambda sigma: clipped_mean(0.13, sigma) - theta,
    0.25, 0.40, xtol=1e-15
)
print("sigma giving population mean theta:", s)
print("population endpoints for c in [.12,.14]:",
      clipped_mean(0.12, s), clipped_mean(0.14, s))
print("intercept-interval mass in constant proposal:", 0.02 / 0.25)

# Valid 1,000-tick occupancy fractions, 40 seeds at each cell.
x = np.r_[np.full(5, 0.936), 0.195, np.full(34, 0.010)]
i, j = np.indices((100, 100))
idx = (np.arange(40)[:, None, None]
       + 4*i[None, :, :] + 12*j[None, :, :]) % 40
X = x[idx]
residual = X - X.mean(axis=0)
box = sum(
    np.roll(np.roll(X, dx, axis=1), dy, axis=2)
    for dx in (-1, 0, 1)
    for dy in (-1, 0, 1)
) / 9.0

sigma_bin = float(x.std(ddof=1))
a2 = float(np.median(box.std(axis=0, ddof=1) / np.sqrt(40)))
rho1 = float(
    np.sum(residual * (
        np.roll(residual, -1, axis=1)
        + np.roll(residual, -1, axis=2)
    )) / (2 * np.sum(residual**2))
)
assert 0.12 < x.mean() < 0.14
assert a2 < 0.02
assert rho1 <= 0
assert abs(clipped_mean(0.13, sigma_bin) - theta) < 0.001
print("bin mean / SD:", float(x.mean()), sigma_bin)
print("A2 median SE / pooled rho1:", a2, rho1)
print("population mean at c=.13:", clipped_mean(0.13, sigma_bin))
~~~
