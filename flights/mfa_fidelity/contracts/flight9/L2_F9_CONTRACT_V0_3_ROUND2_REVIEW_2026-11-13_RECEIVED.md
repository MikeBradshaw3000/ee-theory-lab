## 3. Q2 — Exact pruning and the build obligation

**ACCEPTABLE.**

Let \(n=|E|\), sort the observed-to-contour distances as \(d_{(0)}\le\cdots\le d_{(n-1)}\), and put

\[
j=\lfloor0.95(n-1)\rfloor,\qquad
\gamma=0.95(n-1)-j.
\]

The interpolated quantile is \((1-\gamma)d_{(j)}+\gamma d_{(j+1)}\), with the usual endpoint interpretation when \(\gamma=0\). If it is at most ε, then \(d_{(j)}\le\epsilon\). Thus **at least \(j+1\) distances must be at most ε**. This is necessary, not sufficient. It does not require the upper interpolation endpoint to be at most ε.

If a contour bond is within ε of an observed bond midpoint e, each of its incident cell centres is within ε + 0.5 of e. For the superlevel convention \(\{\lambda\ge\ell\}\), one incident cell is below ℓ and the other is at least ℓ. Therefore its level necessarily lies in

\[
\min(\lambda_{\text{near cells}})<\ell
\le\max(\lambda_{\text{near cells}}).
\]

EP::Family.admissible uses exactly the necessary count \(j+1\), a strict lower endpoint and an inclusive upper endpoint. Its small expansion of the spatial-query radius only retains extra candidates. Since the joint S includes this global directed quantile, every passing joint candidate survives the pruning. Adding the component terms cannot invalidate that implication. [C §5.5 steps 6–7; EP::Family.admissible.]

**The fitted-level tie rule is also preserved when a pass exists.** Discarded contours have S > ε. They cannot beat or tie a retained minimum at or below ε. Levels are visited in increasing order and the prototype updates only for strict improvement, preserving the lowest minimizing level. For an adverse result, the minimum over examined contours is a descriptive value and need not equal the full-family minimum. The draft correctly makes that distinction. [C §5.5 step 7; EP::evaluate.]

**Build obligation.** The proof supplies the general justification; finite corpus agreement alone would not prove exactness. Together with that proof, the build obligation is suitable if “agreement” means agreement for **each point-map decision and each valid resample**, not just matching final 950-vote labels. Include interpolation-boundary cases, equality at ε, strict/inclusive level endpoints, periodic wrapping, zero admissible candidates, and lowest-level ties. The Q4/Q9 counterexamples should join that corpus. Compare full minimizers/ties for passing cases; do not require equality of adverse descriptive minima.

The five supplied point checks reproduce their pruned/brute agreement. That is positive evidence for the prototype, not substitute qualification of a future instrument. [PC; §12.2 below.]

## 5. Q4 — Component convention

**REQUIRES CHANGE. The prototype implements the written convention, but that convention does not identify connected boundary components on a torus.**

A pair consisting of one occupied-region component and one background component can share more than one disconnected boundary loop. Even a simple wrapping strip has two such loops. Labelling bonds only by the two region IDs merges them. The following construction shows that the merger affects the claimed protection.

On the 100×100 torus, with integer cell coordinates, set

\[
a(y)=
\begin{cases}
2,&y\text{ even},\\
40,&y\text{ odd},
\end{cases}
\quad
M=\{a(y)\le x<60\},\quad
R=\{a(y)\le x<70\}.
\]

Use the boundary of M as the predicted contour and that of R as the observed edge. Each foreground is 4-connected and each complement is 8-connected. Each boundary nevertheless has a common long zigzag loop and a separate straight loop. [L2 synthetic construction; EP::edge and EP::S_joint; Appendix R.]

| Quantity | Verified result |
|---|---:|
| Predicted region / observed region | 3,900 / 4,900 cells |
| Common zigzag loop | 3,900 bonds |
| Separate straight loop, each side | 100 bonds |
| Displacement of the straight loop | 10 cells |
| Component size under the region-pair convention | One 4,000-bond component on each side |
| Global directed Q95, both directions | 0 |
| Joint S under the draft convention | **0** |
| Q95 for each separately traced straight loop | **10** |

The displaced loop is resolved under m = 40 but supplies only 2.5% of the merged pair's perimeter. It disappears from both pair quantiles.

This is not excluded by the 3×3 estimator. I constructed valid integer per-seed occupancy counts from 195 to 207 out of 1,000. Exact integer convolution verifies a smoothed map of 0.201 inside R and 0.199 outside. With 40 identical synthetic count maps, every bootstrap draw is identical. A complete binary-index family containing M as its sole proper superlevel mask returns \(n_C=1000,n_A=n_I=0\). This is a synthetic counterexample to the component convention, not a claim that this binary index is one of the canonical terrains.

A hole must remain separately represented. The construction above has no ambiguous saddle junction, so a junction convention alone cannot repair it. Add this exact case to the deterministic corpus and verify its short-loop term is 10. The pruning proof remains valid after that repair because S still includes the same global directed term.

## 6. Q5 — Contour constancy and its noise reference

**REQUIRES CHANGE. Reporting-only status does not make the stated inference valid.** There are two separate problems. [C §§1.3(b), 1.5 A8, 5.7.]

### 6.1 The noise must be centred in the same way as the numerator

Let \(X_s\) denote one seed's unsmoothed occupancy map, \(\mu=E[X_s]\), and \(\Sigma=\operatorname{Cov}(X_s)\). Let P subtract the cell mean separately inside every fixed bin. With population-denominator within-bin variances, the proposed numerator is

\[
V_{\mathrm{within}}=\frac{\|P\bar X\|^2}{N},
\]

and independence across the 40 seeds gives

\[
E[V_{\mathrm{within}}]
=\frac{\|P\mu\|^2}{N}
+\frac{\operatorname{tr}(P\Sigma)}{40N}.
\]

The proposed mean of per-cell variances divided by 40 estimates \(\operatorname{tr}(\Sigma)/(40N)\), not the second term above. Bin centering removes some noise; within-map covariance changes how much. The variance denominator convention is also unspecified. Under independent equal cell variances and 100-cell bins, a population-denominator within-bin variance gives a noise factor of 0.99. An unbiased per-bin variance fixes that special case, not the general covariance problem. Nor is the expectation of a random ratio generally the ratio of expectations.

A direct repair, for the stated population-denominator numerator, is

\[
\widehat V_{\mathrm{noise,within}}
=\frac{1}{40\cdot39\cdot N}
\sum_{s=1}^{40}\|P(X_s-\bar X)\|^2.
\]

It applies the same spatial projection to the residual maps and estimates the actual noise contribution, including spatial dependence. An analogous formula can be specified for another explicitly chosen variance convention. This repairs the noise estimand; it does not by itself establish an exact expected ratio of one or a calibrated null interval.

### 6.2 Finite-width bins contain legitimate variation under the alternative

Even with that repair, \(\|P\mu\|^2/N\) can be positive when \(\mu_i=h(\lambda_i)\) exactly. A bin containing several λ values contains variation of h. Reporting its width neither subtracts nor bounds that variation when h is unspecified.

For example, take 10,000 equally spaced λ values, \(h(\lambda)=0.06+0.40\lambda\), 100 bins of 100 cells, independent centred seed noise of standard deviation 0.001, and 40 seeds. The within-bin signal variance is approximately \(1.33346668\times10^{-6}\); mean-map noise variance is \(2.5\times10^{-8}\). With population-denominator bin variances, the ratio of expected variances is approximately **54.33**, despite the population mean being exactly a function of λ alone. Bounded centred noise can be used, so this example requires no clipping. This is an analytic counterexample, not a Flight 9 simulation.

**Required choice:** either use exact declared contour groups with a corresponding noise estimate and explicit treatment of ties/group sizes; or specify a null/reference that includes the within-bin variation permitted by the particular independent-response model; or retain the coarse-bin report as descriptive and remove the claim that excess over this noise reference alone is evidence against arbitrary \(p=h(\lambda)\). ## Appendix R — Reproducing the two geometric counterexamples

This short program uses only the received terrain builder, probe **formula functions**, and synthetic evaluator. It runs no lattice dynamics and reads no probe observation file. Save the code as a Python script and pass the extracted packet directory as its sole argument. The full-family TC calculation uses all candidates without pruning; equality of its global lower bound and an attained joint value certifies each joint minimum.

The 1,000 bootstrap support counts follow from giving all 40 seeds the same constructed integer count map. The code verifies the map and point decisions; it does not perform redundant identical resamples.

    from pathlib import Path
    import sys
    import numpy as np
    from scipy.spatial import cKDTree

    root = Path(sys.argv[1]).resolve()
    arith = root / "flights/mfa_fidelity/contracts/flight9/arith_v0_3"
    sys.path.insert(0, str(arith))
    import f9_evaluator_proto as E
    import f9_terrains as T

    L = 100

    def counts_for(mask):
        # Invert the periodic box mean, then certify the result in integers.
        signed = np.where(mask, 1, -1)
        f = (1 + 2*np.cos(2*np.pi*np.arange(L)/L))/3
        inverse = np.fft.ifft2(
            np.fft.fft2(signed)/(f[:, None]*f[None, :])
        ).real
        A = 200 + np.rint(inverse).astype(np.int64)
        summed = sum(
            np.roll(np.roll(A, i, 0), j, 1)
            for i in (-1, 0, 1) for j in (-1, 0, 1)
        )
        assert np.array_equal(summed, 9*(200 + signed))
        assert 0 <= A.min() <= A.max() <= 1000
        assert np.array_equal(E.box(A/1000) >= .2, mask)
        return A

    def bonds(mask):
        points = []
        for axis in (0, 1):
            i, j = np.nonzero(mask != np.roll(mask, -1, axis))
            points.append(
                np.column_stack(((i+.5) % L, j))
                if axis == 0 else
                np.column_stack((i, (j+.5) % L))
            )
        return np.concatenate(points)

    def global_score(a, b):
        return max(
            E.q95(cKDTree(b, boxsize=L).query(a)[0]),
            E.q95(cKDTree(a, boxsize=L).query(b)[0])
        )

    # Q4: two disconnected loops merged by one region/background pair.
    x, y = np.indices((L, L))
    a = np.where(y % 2 == 0, 2, 40)
    predicted = (x >= a) & (x < 60)
    observed = (x >= a) & (x < 70)
    ep, ec = E.edge(observed)
    cp, cc = E.edge(predicted)
    d = cKDTree(cp, boxsize=L).query(ep)[0]
    straight = np.isclose(ep[:, 0], 69.5)
    assert len(ep) == len(cp) == 4000
    assert len(np.unique(ec)) == len(np.unique(cc)) == 1
    assert straight.sum() == 100
    assert E.q95(d[straight]) == 10
    assert E.S_joint(ep, ec, cp, cc) == 0
    A = counts_for(observed)
    q4 = E.evaluate(A/1000, E.Family(predicted.astype(float)), .2)
    assert q4["informative"] and q4["within"]
    print("Q4:", int(A.min()), int(A.max()), q4)

    # Q9: actual TC arrays, translated highest rounded-P contour.
    probe = root / "flights/mfa_fidelity/design/flight9/probe/f9_probe.py"
    P = T.load_probe(str(probe))
    v, u, r = T.all_terrains(P)["TC"]
    lam = {
        name: T.quantize(P.compose(name, v, u, r))
        for name in ("P", "H")
    }
    observed = np.roll(lam["P"] >= .729, 2, axis=0)
    A = counts_for(observed)
    ep, ec = E.edge(observed)
    assert observed.sum() == 739 and len(ep) == 396
    print("TC counts:", int(A.min()), int(A.max()))

    for name in ("P", "H"):
        family = E.Family(lam[name])
        best_global, level = min(
            (global_score(ep, bonds(lam[name] >= level)), float(level))
            for level in family.levels
        )
        cp, cc = family.contour(level)
        attained_joint = E.S_joint(ep, ec, cp, cc)
        assert attained_joint == best_global
        result = E.evaluate(A/1000, family, .2)
        assert result["within"] == (name == "P")
        print(name, len(family.levels), best_global,
              attained_joint, level, result)
